Techniques applied

  1. Split the work by trust. Code writes every product, quantity, lot and recall number from the database. The model writes only the wording, and a checker flags any digit, code, product name or action word it adds.
  2. Embeddings in the database. qwen3-embedding-8b vectors for every recall and inventory line, stored in Akamai PostgreSQL with pgvector, so one SQL query ranks every held pair by meaning. Cached, so a re-run embeds nothing it has already seen.
  3. Reciprocal rank fusion. Meaning alone buried the carrots (7th on the sheet, 380th by meaning). Fusing the two rankings keeps a pair near the top if either signal ranks it high.
  4. Read the top, cache the verdicts. qwen3-8-27b reads only the first 36 pairs and quotes its reason; verdicts are cached in PostgreSQL. A verdict reorders a line; it never clears one.
