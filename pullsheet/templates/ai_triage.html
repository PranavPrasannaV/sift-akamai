Held lines: what to read first

AI reading order — a person decides. Every line here stays HELD until someone clears it on its match page.

Sift holds a line whenever the evidence is not strong enough to pull it, and never clears one by itself. That is safe, and it leaves a long list. This page orders that list. Each held pair is placed by meaning: both descriptions are embedded with {{ models.embedding }}, the vectors are stored in Akamai PostgreSQL (pgvector), and their cosine distance is measured in one query. That order is fused with the pull sheet's own rule-based order (reciprocal rank fusion), so a pair either signal ranks high stays near the top. The first {{ read_top }} pairs are then read by {{ models.chat }}, which answers same, maybe or different and quotes the words that decide it.
